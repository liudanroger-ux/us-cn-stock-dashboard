# US-China Stock Sector Dashboard | 中美行业龙头对比看板

A real-time comparison dashboard for US and Chinese stock market sector leaders, covering 19 industry sectors and 4 concept sectors (AI Hardware, AI Software, Pharma, Electrical Equipment) with 1,277 stocks.

中美行业龙头对比看板 — 覆盖 19 个行业板块 + 4 个概念板块，共 1,277 只个股的实时涨跌、市值、PE 数据对比。

## Features

- 23 sectors (19 industry + 4 concept)
- Price change % calculated from last valid trading day close (handles weekends correctly)
- Mobile-responsive design with hamburger menu
- Sorted by absolute change percentage (hot stocks first)
- PE ratio and market cap data

## Tech Stack

- Pure HTML + CSS + JavaScript (no frameworks)
- Data generated by Python script (`collect_data.py`) using Yahoo Finance API

## Data Update

Data is updated daily via automated script. To update manually, regenerate `data.js` from the data collection script.
